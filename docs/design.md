# 絕對音感・卡點挑戰 — 設計

日期：2026-11-26

## 目的
同一台電腦輪流玩的卡點小遊戲。玩家聽《I Will Always Love You》，憑耳朵在鼓聲進來的瞬間按下按鈕，越接近卡點分數越高，最後看排行榜比輸贏。

## 目標
- 播放本機影片 `Whitney Houston - I Will Always Love You.mp4`（27.2 秒剪輯版）
- 畫面顯示即時秒數（小數點第二位）
- 按鈕用 sakuga-vfx `<sakuga-button>`（ドン! 衝擊特效），每局只能按一次
- 卡點時間一到就結算，用星星評分（sakuga-vfx `<sakuga-rating>` 的風格，補做半星）
- 排行榜：依差距由小到大排序

## 非目標
- 不做線上多人、帳號、後端
- 不嵌入 YouTube

## 規則
- 卡點：`22.11` 秒（鼓聲 21.87 s 開始、約 22.35 s 被歌聲蓋過，取中間值）
- 差距 = |按下時間 − 卡點|
- 星星 = `max(0, 5 − 0.5 × floor(差距 ÷ 0.3))`
- 按下後 0.5 秒跳結算畫面、影片暫停，這局結束（卡點前、後按都算）
- 一直沒按 → 卡點後 3 秒（再按也是 0 星）直接結算，0 顆星，記為「沒按」

## 做法
| 方案 | 取捨 | 決定 |
|---|---|---|
| 單一靜態 `index.html` + 複製進來的 sakuga 元件 | 雙擊就能玩、不用安裝 | ✅ 採用 |
| React / Vite 專案 | 對這個規模太重 | ✗ |
| 嵌 YouTube | 使用者已有剪好的檔案 | ✗ |

## 畫面
1. 開始：輸入名字 → 開始
2. 遊戲：影片 + 大計時器 + ドン! 按鈕
3. 結算：按下時間 / 卡點 / 差距 / 星星
4. 排行榜：名次、名字、按下時間、差距、星星；「下一位」、「清空排行榜」

## 風格
跟 sakuga-vfx 一致：白紙底、淡紫與紫色線條、粉紅點綴、漫畫狀聲字。

## 留給實作者的決定（我的判斷）
- 排行榜存在瀏覽器 localStorage
- 計時以 `video.currentTime` 為準，用 requestAnimationFrame 更新顯示
- 卡點時間不顯示給玩家
