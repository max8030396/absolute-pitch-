# 絕對音感・卡點挑戰 

聽《I Will Always Love You》（Whitney Houston），在鼓聲進來的瞬間按下按鈕，越接近卡點星星越多。同一台電腦輪流玩，最後用頒獎台揭曉前三名。

**怎麼開**：整個資料夾放在一起，雙擊 `index.html` 就能玩（建議 Chrome / Edge）。不用安裝、不用架伺服器。

---

## 搬資料夾須知

- **整個資料夾一起搬**就好。所有檔案都用相對路徑互相引用，資料夾名稱和位置都可以改。
- 影片和三個音效檔必須和 `index.html` 放在**同一層**，檔名也不能改。要改檔名，就要一起改 `index.html`（影片）和 `js/game.js`（音效）。
- **排行榜存在瀏覽器裡（localStorage），不在資料夾裡。** 換電腦、換瀏覽器或清除瀏覽資料，排行榜就會不見；搬資料夾後也可能讀不到舊紀錄。要保留結果，請在搬之前先截圖。
- 標題字型從 Google Fonts 載入，沒網路時會換成系統內建字型，遊戲照樣能玩。

## 遊戲規則（目前版本）

1. 輸入名字 → 開始，影片從 0 秒播放，畫面由上到下是：**秒數（小數第二位）→ 影片 → 按鈕**。
2. 按「就是現在！」或空白鍵，**每局只認第一次**。按下的瞬間（pointerdown，不是放開）記錄影片時間，同時響鑼聲。
3. **按下後 0.5 秒跳單局結算**，影片暫停，這局結束。卡點前或卡點後按都算。
4. 一直沒按：卡點後 3 秒（25.11 秒，再按也是 0 星）自動結算，記為「沒按」。
5. 計分：`星星 = max(0, 5 − 0.5 × floor(差距 ÷ 0.3))`，差距 = |按下時間 − 卡點|，先取到 0.01 秒再算，避免浮點誤差。
   - 例：差 0.23 → 5 星；差 0.51 → 4.5 星；差 1.32 → 3 星；差 ≥ 3.00 → 0 星
6. 排行榜依差距由小到大排序，同分時先玩的人排前面，沒按的排最後。
7. 排行榜的「結算」→ 最終結算頒獎台，只顯示前三名；「新的一場」確認後清空排行榜。

### 可調整的設定（`js/game.js` 最上面）

| 設定 | 目前值 | 說明 |
|---|---|---|
| `HIT_TIME` | `22.11` | 鼓聲卡點（秒） |
| `SETTLE_DELAY_MS` | `500` | 按下後幾毫秒跳結算 |
| `NO_PRESS_GRACE` | `3` | 沒按的話，卡點後幾秒判定 |
| `SFX` | 檔名、起播點、音量 | 鑼聲從 0.14 秒開始播，因為檔案開頭有 0.16 秒空白 |

每 0.3 秒扣半星的 `STEP` 在 `js/score.js`。

## 卡點怎麼來的（22.11 秒）

用 `tools/audio/` 的腳本分析影片音軌（每 5 毫秒看一次音量）：

- 18～21.8 秒幾乎無聲（約 −38 dB）
- **21.87 秒**鼓擊：音量瞬間衝到 −9 dB，低頻和高頻同時爆出
- 鼓聲衰減到**約 22.35 秒**被下一個聲音（歌聲）蓋過
- 取中間值：(21.87 + 22.35) ÷ 2 ≈ **22.11 秒**（結束點抓早或晚 0.02 秒，中間值落在 22.10～22.12，不影響評分）

重跑分析需要 Python 和 `av`、`numpy` 套件：

```sh
python -m venv venv && venv/Scripts/pip install av numpy
venv/Scripts/python tools/audio/onset.py "Whitney Houston - I Will Always Love You.mp4"   # 每秒概況 + 最強起音點
venv/Scripts/python tools/audio/zoom.py  "Whitney Houston - I Will Always Love You.mp4"   # 20.5~24.5 秒逐 20ms 音量
venv/Scripts/python tools/audio/edge.py  "Whitney Houston - I Will Always Love You.mp4"   # 鼓聲起點、下一個聲音起點
venv/Scripts/python tools/audio/lead.py  敲鑼音效.wav 結算音效.wav 0星音效.mp3          # 音檔長度、開頭空白
```

## 最終結算的演出時間軸

| 時間 | 畫面 | 合成音效（`js/finale-sfx.js`） |
|---|---|---|
| 0.3 秒 | 「最終結算」標題砸下 | `slam` 低音咚 |
| 0.9 秒 | 第 3 名升起，ポン | `pon` 彈跳音（1.08 秒） |
| 1.8 秒 | 第 2 名升起，ズザッ | `zuza` 滑地 + 悶響（1.98 秒） |
| 2.7 秒 | ゴゴゴゴ 蓄力 | `gogo` 轟鳴 + 加速小鼓連打，1.15 秒漸強 |
| 3.7 秒 | 第 1 名升起、皇冠、光芒、ドン! | `don` 重低音 + 銅鈸（3.88 秒），同時播 `結算音效.wav` |
| 4.2／4.4 秒 | 閃光 | `kira` 叮 ×2 |
| 4.6 秒 | 出現「回排行榜」「新的一場」按鈕 | — |

不足三人時，空位顯示「？？？ 從缺」、台子變暗，不播該名次音效。

## 驗證方式

- 計分測試：`node --test tests/`
- 自動玩一遍：`tools/e2e/` 的腳本用 headless Chrome（`C:/Program Files/Google/Chrome/Application/chrome.exe`）。先在 `tools/e2e/` 執行 `npm i puppeteer-core@23.11.1`，然後：
  - `node shot.cjs out 1280 860`：開始 → 遊戲 → 按下 → 結算 → 排行榜，各截一張
  - `node rule.cjs out`：提早按、卡點後按、沒按三種情況的結算時機
  - `node sfx2.cjs`：各種情況播放的音效
  - `node finale.cjs out 1280 860 5`：最終結算各階段截圖（最後一個數字是假玩家人數）
  - `node fsfx.cjs 預覽.wav`：渲染合成音效試聽檔，並列出各音效觸發時間
  - `node reset.cjs`：「新的一場」有清空排行榜
